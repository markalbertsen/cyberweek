# Cyberweek – Skoleprosjekt

Velkommen! 🎉  
Dette repoet er startpunktet for oppgavene dere skal gjøre.  
Følg instruksjonene nøye for å levere inn arbeidet deres.

---

## 🚀 Hurtigguide (for de utålmodige)
1. **Fork repoet** (knappen øverst til høyre).
2. **Klon** din fork:
   ```bash
   git clone https://github.com/<ditt-brukernavn>/<repo-navn>.git
````

3. **Lag branch**:

   ```bash
   git checkout -b <fornavn-klasse>
   ```
4. **Commit & push**:

   ```bash
   git add .
   git commit -m "Levering <fornavn>"
   git push -u origin <fornavn-klasse>
   ```
5. **Åpne Pull Request (PR)** fra din fork til dette repoet.

---

## Oppgave 1 – AI Chat Tool

Bygg en enkel chat-applikasjon med en **Node.js-backend** som kobler seg til **OpenAI API**.

**Krav:**

* Koble Node.js til OpenAI API.
* Støtt minst én respons-modus (direkte forespørsel, streaming eller strukturert output).
* Lag et tydelig og brukervennlig grensesnitt.
* Legg gjerne til noe kreativt ekstra! ✨

---

## Oppgave 2 – AI-integrert nettside

Lag en liten nettside som integrerer **AI på en kreativ måte**.
For eksempel: svare på spørsmål, generere innhold, analysere input eller gi interaktive funksjoner.

**Krav:**

* Ha minst én AI-drevet funksjon.
* Presenter resultater på en **interaktiv** eller **visuelt engasjerende måte**.
* Hold løsningen **lettvekts og gøy**.

## 📦 Full leveringsguide (detaljert)

1. **Fork dette repoet**
   Klikk på **Fork**-knappen øverst til høyre.
   → Du får da en kopi av dette repoet i din egen GitHub-konto.

2. **Klon repoet ditt**

   ```bash
   git clone https://github.com/<ditt-brukernavn>/<repo-navn>.git
   ```

3. **Lag en branch med ditt navn og klasse**

   ```bash
   git checkout -b <fornavn-klasse>
   ```

4. **Jobb med oppgaven og lag commits**

   ```bash
   git add .
   git commit -m "Levering <fornavn>"
   ```

5. **Push branchen til din fork**

   ```bash
   git push -u origin <fornavn-klasse>
   ```

6. **Send inn en Pull Request (PR)**

   * Gå til din fork på GitHub.
   * Klikk **Contribute → Open pull request**.
   * Velg `main` i dette repoet som mål.
   * Gi tittelen: `<Navn> – Levering`.
   * Skriv en kort beskrivelse av hva du har gjort.

---

## Viktig 🚨

* Ikke push direkte til `main`.
* Hver elev skal levere på **sin egen branch**.
* Alle leverer ved å sende inn en **Pull Request (PR)**.
